Thanks for the quick fix! I built the PR at `dd3a8aa` and the base `db4eef4` the same way (`CGO_ENABLED=0`, linux/arm64) and ran both through the same checks.

The reported problem is fixed: with `ulimit -f 0`, `main.tf` keeps its 84 bytes, and killing the process before each of its 3 file operations left either the original or the formatted file every time (on the base, one of its 2 kill points left it at 0 bytes).

Two things behave differently from the base, though:

**1. A relative symlink is resolved from the working directory, not from the link's directory.** When a file with that name exists at the wrong place, it is overwritten and `fmt` exits 0:

```
$ ls -l mod/versions.tf
lrwxrwxrwx ... mod/versions.tf -> ../versions.tf
$ cat ../versions.tf            # outside this directory, unrelated
# not part of this repo
locals {
  keep = "me"
}
$ terraform fmt mod; echo "exit $?"
mod/versions.tf
exit 0
$ cat ../versions.tf            # now holds the formatted ./versions.tf
terraform {
  required_version = ">= 1.0"
}
```

`./versions.tf`, the real target, is left unformatted. When nothing exists at the wrong place, `fmt` fails instead (`Error: Failed to write ../shared/main.tf`, exit 2). Run from inside `mod/`, it works, which may be why the tests pass. The base formats the real target in all three cases. `os.Readlink` returns the target relative to the link's directory; resolving it with `filepath.Join(filepath.Dir(path), target)`, or using `filepath.EvalSymlinks(path)` (which also follows chains), might fix it — I haven't tried either.

**2. File permissions become `0644`.** `.tf` files with `0600`, `0664` and `0755` all end up `0644` after `fmt`, because `AtomicWriteFile` chmods the temporary file to the `perm` it is given. `os.WriteFile` did not change the mode of an existing file. Passing the original file's mode might keep it.

Not checked: owner and group, hard links, power loss, Windows.

Disclosure: as with the report, I used an AI assistant (Claude) to run these comparisons and draft this comment, and checked it against the runs.
