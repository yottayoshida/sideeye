# Scout 4 (fresh Opus subagent, read-only; 2026-10-07). Its report, as handed back.

sideeye dogfood の候補集め、4 回目の結果です。fresh で、星 1,000 以上・2026-04-07 以降に push・archive されていない・issue が有効、を満たし、書き換えるコマンドをソースか公式文書で確かめたのは 20 件です。規則 11 は測っていません。ファイルは作っておらず、使ったのは fresh.sh・`gh api repos/…`（contents・releases・tags を含む）・読み取りのシェル・Web 取得だけです（`gh api search` は使っていません）。

【要判断】
1. 20 件のうち 13 件は、AI エージェントとその周辺の設定を書く CLI です。gemini-cli と codex を測ったのと同じ種類なので、波に何件まで入れるか決めてください。仕組みも既に知られているものがあります。
   - qwen-code は gemini-cli の fork で、`mcp add` も同じ形です。
   - mini-swe-agent の `config set` は python-dotenv の `set_key` で書いています。python-dotenv は測定済みです。
2. hermes-agent・forgecode・promptfoo は、コマンドが書くのは YAML か TOML です。ただ、道具の主な保管先は SQLite です（会話・評価。hermes は state.db、forge は diesel の conversations、promptfoo は promptfoo.db）。規則 6・7 で入れるか決めてください。
3. code-server と vscode は同じコードで拡張を管理しています。どちらか 1 つで足ります。
4. 指定された分野はほぼ全部 SEEN でした。中身は次のとおりです。
   - シェル・端末: starship、oh-my-posh、sheldon、fish、hstr
   - ディレクトリ移動: zoxide、autojump、gsamokovarov/jump
   - 画像: svgo、gifsicle、pngquant、jpegoptim、zopflipng、ECT、Leanify、caesium、imgp、jhead
   - フォント: fontforge
   - config set: npm、pnpm、pip、uv、gh、go env、pdm、hatch、conan、spack、pixi、composer、luarocks
   - 照合で気づいた分: perl -i は 10-03 に PASS で測定済みです。dvc も既に測っています（照合は「DVCS」に当たるので、名前だけでは fresh に見えます）。
   - PDF（qpdf と mutool 以外）・ゲームのセーブ・ブラウザ拡張・SQLite でないノートは、条件を満たす fresh が見つかりませんでした。
