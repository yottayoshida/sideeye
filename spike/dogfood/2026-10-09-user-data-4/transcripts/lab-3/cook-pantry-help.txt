Manage pantry inventory with full CRUD support and recipe-based analysis

Usage: cook pantry [OPTIONS] <COMMAND>

Commands:
  depleted  Show items that are out of stock or have low quantities
  expiring  Show items that are expiring soon
  recipes   List recipes that can be made with items currently in pantry
  plan      Analyze ingredient usage across recipes to help plan pantry items
  list      List all items in the pantry
  add       Add an item to the pantry
  remove    Remove an item from the pantry
  update    Update an item already in the pantry
  help      Print this message or the help of the given subcommand(s)

Options:
  -b, --base-path <PATH>
          Base path for recipes and configuration files

  -v, --verbose...
          Increase verbosity (-v for info, -vv for debug, -vvv for trace)

  -f, --format <FORMAT>
          Output format

          Possible values:
          - human: Human-readable output (default)
          - json:  JSON output
          - yaml:  YAML output
          
          [default: human]

  -h, --help
          Print help (see a summary with '-h')
